# Proposal

## Why

用户希望将有线外接显示器作为全屏阅读画面，同时把 iPhone／iPad 当作带光标的触控板。现有阅读器仅有普通多窗口和离散外设命令，不能在独立外屏上延续同一会话并完成目录、设置、评论等操作。

## What Changes

- 小说、漫画阅读器在外屏可用时自动接管：阅读中插线立即进入，先插线再进入阅读器也自动开启；普通页面不主动打开阅读器。退出阅读或断线后恢复设备界面与阅读位置。
- 外屏全屏独立排版，默认隐藏工具栏，保留当前阅读设置；布局依据外屏视口而非连接设备类型，内容不拉伸、不为铺满屏幕强行裁切。
- 设备通常只显示居中的浅灰色文字“当前设备作为触控板”，保持唤醒；单指相对移动光标、轻点点击，空闲约 3 秒隐藏光标。
- 双指优先拖动光标下的控件，其次平移放大的漫画，其他情况下按模式滚动或翻页；捏合缩放漫画，各操作互斥。
- 外屏光标可操作阅读工具栏、目录、设置和评论。文字输入及必要系统交互临时交给设备，结束后恢复触控板，外屏不呈现这些交互的敏感内容。
- 同一阅读会话只有一个有效阅读视口；锁屏或切到其他 App 时暂停遥控并停止外显阅读内容，返回后自动恢复；多窗口选择最近操作的阅读器，接管后固定会话。
- 不增加手动开启按钮、退出触控板手势或独立模式开关；通过外屏返回按钮退出阅读，或拔线回到设备继续阅读。

### Non-goals

- 本期支持与验收范围为支持视频输出的 iPhone／iPad 有线连接；不承诺 AirPlay 体验，也不新增无线连接管理。
- 不投放整个 App、普通帖子或 Blog，不提供跨 App 系统鼠标、远程桌面、多个外屏同时阅读或锁屏触控。
- 不新增数据源、同步格式、Swift package target 或第三方依赖；不以任何现有模块拆分规划为前置条件，也不修改其文件。

## Capabilities

### New Capabilities

- `external-display-reading`：独立全屏阅读、会话和位置交接、多窗口归属、生命周期及设备端交互例外。
- `reader-trackpad-control`：触控板提示、虚拟光标、点击与双指手势仲裁、面板操作和输入隔离。

### Modified Capabilities

无。现有主规格覆盖网络安全验证，不改变其要求。

## Impact

- App 与平台入口：`YamiboX/YamiboXApp.swift`、Scene 配置及 `Sources/YamiboXUI/AppEntry` 的窗口、焦点和生命周期接线。
- 阅读器：`Sources/YamiboXUI/Features/Reader` 下的会话、小说／漫画根视图、视口、工具栏、面板、评论与设备输入桥接；必要的阅读流程调整仍归 `Sources/YamiboXCore/Reader`。
- 兼容性：保留 iOS 18+、既有设备端交互、键盘／手柄、预览语义及持久化格式；采用公开平台 API，按系统可用性接入外屏生命周期。
- 验证：使用签名 `YamiboX-Local`、iOS 模拟器和本地论坛，记录模拟器外屏及完整操作链；当前测试 App 仅支持模拟器，真实 DP 链路与锁屏行为需另获真机测试授权后验收，不擅自扩大构建配置或切换普通 App／生产论坛。不新增单元测试或测试 target。
