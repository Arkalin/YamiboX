# Tasks

以下均为尚未执行的实施任务。本轮只更新规划；启动实施需要新的明确请求。现有代码调整不自动计为本变更完成，必须逐项核对本次验收标准。

阶段约定：先在现有模块中整理必要契约和实现，再以协调切换批次形成七个实际 targets，完整保护 Reader；Library／Forum 只完成必要归属并登记 design 第 2 节允许的过渡边。任务中“目标归属”不代表尚未切换的 target 已存在。单文件搬迁的静态检查不替代批次结束构建，不为保证每次移动都编译而新增 Legacy／Contracts／Adapter target。

验证约定：构建使用 YamiboX-Local 和可用 iOS 模拟器；交互使用签名的本地测试 App，先读 `docs/tests/launch-arguments.md`，每次启动显式提供 `http://127.0.0.1:8088`。不使用普通 App、生产论坛、已移除的 UI 测试宿主或 swift test。不新增单元测试、测试文件或测试 target；临时编译探针与固定内容装配按 design 的隔离方式执行，确需新增单元测试时另行申请批准。

- [ ] 3.4 建立中立运行时引用到旧数据 DTO／键／路由／锚点的持久化兼容映射；验证：1.1 的本地样本读写往返身份一致，非论坛引用明确拒绝，不修改旧格式或历史迁移。
