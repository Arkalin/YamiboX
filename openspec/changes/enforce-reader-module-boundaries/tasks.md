# Tasks

以下均为尚未执行的实施任务。本轮只更新规划；启动实施需要新的明确请求。现有代码调整不自动计为本变更完成，必须逐项核对本次验收标准。

阶段约定：先在现有模块中整理契约和实现，再协调形成七个实际 targets；第 6 组保持 Reader 完整验收，第 7 组单独验收 Source 并关闭 design 第 2 节列明的全部过渡边。Library/Forum 不做全部内部重构，但其来源/存储实现依赖必须本期退出。任务中的“目标归属”不代表 target 已存在，单文件静态检查不替代批次构建，不为每次移动可编译而新增 Legacy/Contracts/Adapter target。与 `decouple-forum-source` 共用的搬迁仅按本清单执行一次，不自动修改另一变更的任务状态。

验证约定：构建使用 YamiboX-Local 和可用 iOS 模拟器；交互保留签名，先读 `docs/tests/launch-arguments.md`，每次启动显式提供 `http://127.0.0.1:8088`，本地不可用先诊断。不使用普通 App、生产论坛、已移除的 UI 测试宿主或 swift test。不新增单元测试、单元测试文件或测试 target；临时闭包针对 iOS Simulator SDK 编译，最小运行装配仅由现有 Local App 承载，不另装测试 App，不以宿主改名规避单元测试授权。独立编译与同进程未调用真实实现的证据分开记录，各组随实现完成相应文档和验证。
