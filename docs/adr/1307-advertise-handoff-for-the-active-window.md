# 接力活动由最近获得有效焦点的窗口发布

[窗口协调器](../../Sources/YamiboXUI/AppEntry/YamiboWindowCoordinator.swift)跟踪真实的 key-window 通知和输入，不以视图的出现顺序代替窗口焦点。未交互的预热或后台窗口不能开始发布；所有窗口退到后台时，保留最后一个前台所有者的快照。外设重绑不是阅读动作，仍只能由有焦点的窗口接收。

每个窗口拥有[活动发布器](../../Sources/YamiboXUI/AppEntry/ReadingHandoff.swift)，按可见项出现顺序给嵌套阅读器和帖子优先级。账号切换清空活动登记，也刷新已断开的场景，避免旧窗口重连或旧回调结束时恢复上一账号的内容。序列化时在系统载荷预算中计入字典和键的开销。
