# 喜欢 WebDAV 增加条目字段时保留向后兼容

样式、笔记、章节标题作为条目字段演进：新增字段允许缺省，解码时采用默认样式或空值。载荷现行版本为 2，版本编号不必因每次新增可选字段而提升。旧版客户端重新导出时可能丢掉未知字段却不改条目的更新时间；同时间保留本地条目能保护本机已有的样式和笔记，但无法恢复全新安装从未收到的字段。缺失的章节标题可由拥有相同锚点的快照补齐，不作为一次用户编辑处理。

活动条目与裸删除记录分开传输，防止旧快照复活用户删掉的批注，包括被范围合并替代的条目。图片原始字节不在载荷中：其他设备只拿到条目和来源 URL，需要时再向来源取图。这不提供离线图片副本的跨设备恢复。
