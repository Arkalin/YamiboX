# 小说分页几何不随阅读器控件显隐改变

[分页几何、视口和上下工具栏](../../Sources/YamiboXUI/Features/Reader/Novel/Chrome/NovelReaderVerticalBandsPresentation.swift)使用同一套上下预留区域。分散的常量曾让页脚进度摘要遮住最后一行；以工具栏实际测量值反推分页，又会让工具栏和排版互相触发。现在页顶标题常驻预留带内，不需画覆盖正文的底板；页尾使用字体度量和两行摘要的行距来决定预留，跟随 Dynamic Type 而无需第一帧测量。iPad 分页使用状态栏可见时的顶部基准，沉浸模式隐藏状态栏也不能改变页数或移动正文。

竖向模式的边界下拉提示避让已测量的工具栏；首帧尚无测量值时，使用留有间隔的回退值。底部需另留间隔，因为摘要伸到了工具栏测量范围之外。通知提示等顶部工具栏报告高度后再按该高度落位，避免覆盖关闭按钮。固定的检查面板参与容器布局而不覆盖正文，使正文按剩余宽度重新排版。
