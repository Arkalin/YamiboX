# 阅读器和喜欢列表共用批注的视觉语义

[批注样式](../../Sources/YamiboXUI/SharedUI/Annotations/LikeStyleAppearance.swift)从同一套动态系统色派生正文绘制、选择器与列表色条，避免一套固定 RGB 在翻页主题与深浅外观中失去对比。高亮沿用旧透明度以保留现有批注的外观，下划线和色块指示器各自用全强度，避免细线或小色块不可见。

笔记角标采用空心而非实色点，避免与同色高亮融为一体；尺寸随行高变化并限幅，从小字号到辅助功能大字号都不遮住主要文字。TextKit 文本片段包含行间距，角标靠片段上沿而不是以片段顶角为中心；下划线在片段底部以内，紧贴文字而不是落入行间隙。喜欢列表用同一种标记绘制摘录，保留未标记的上下文；单行预览折叠原文换行，避免只显示选区首段。
