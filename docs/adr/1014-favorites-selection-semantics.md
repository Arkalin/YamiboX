# 作品卡选择由全量收藏和当前目录决定

选择随作品而不是代表章节保留；修改筛选不会撤销已有选择。因此，用全量文档和当前目录快照展开作品卡，而不是查正在展示的卡片。否则一张卡因筛选暂时隐藏时，批量操作可能退化为只改代表章节。每次操作建立成员索引并复用查询，而不是对每张选择卡重新遍历整库。章节归档视图本身按单章选择，不再次展开。

批量标签与位置变更、位置勾选状态使用同一展开规则，避免界面按一章显示、提交时却改变整组。使用者关闭智能漫画批量删除时，作品卡仍可用于其他批量动作，但删除跳过整张作品卡；单章删除要在归档内执行。直接删除代表章节会留下其他成员，并改变作品卡所代表的数据。

只有纯条目选区才能新建收藏夹：该操作会把所选收藏移入新夹，而收藏夹不能嵌套。

「从当前位置移除」是本地操作，并保留条目的最后一个位置；「彻底删除」另行决定是否同步删除论坛收藏。所有入口使用同一记忆选项；候选没有论坛收藏时不询问。判断是否询问必须覆盖所有实际将被删除的成员，不能只用代表章节推断。界面以单条收藏与批量选择两种主体完成确认，而核心命令处理最新持久化数据。

实现见[选择与删除](../../Sources/YamiboXUI/Features/Favorites/Engine/FavoriteLibraryOrganizer%2BSelection.swift)及[收藏页协调器](../../Sources/YamiboXUI/Features/Favorites/Engine/FavoriteLibraryOrganizer.swift)。
