# Keep native page turns and reader chrome on the geometry they display

- [Attached page information](../../Sources/YamiboXUI/Features/Reader/Shared/Chrome/ReaderAttachedPageInformation.swift) receives explicit presentation settings because UIKit page hosts do not inherit the reader's SwiftUI environment. Updating that channel does not replace the text or image host or cancel a native zoom. A vertical reader has no per-page host, so its device menu uses a read-only information overlay. [Information transitions](../../Sources/YamiboXUI/Features/Reader/Shared/Chrome/ReaderInformationAnimation.swift) retain one title/plate channel and cancel obsolete publications when a host is reused or chrome changes rapidly.
- The paged novel's [shared bottom geometry](../../Sources/YamiboXUI/Features/Reader/Shared/Chrome/ReaderProgressPresentation.swift) uses the same padding and two-line spacing for rendering and the [reserved page footer](0901-keep-novel-pagination-independent-of-chrome.md). The reservation excludes the safe area already accounted for by pagination. The vertical scrubber takes the actually displayed capsule count so the optional annotation capsule cannot shift it away from the action row.
- [Scrubbing](../../Sources/YamiboXUI/Features/Reader/Shared/Chrome/ReaderChromeProgress.swift) maps to actual anchors instead of equally spaced ranks: spreads can skip anchors and leave a one-page final spread. Chapter feedback checks the tick at or before the destination and starts from the chapter covering the resting position; a fast jump across a chapter must be detected without firing a false crossing on the first update. The reader-owned tick initializer accepts a normalized index; the public path still normalizes caller data. Both readers share [haptic preparation and feedback](../../Sources/YamiboXUI/Features/Reader/Shared/Chrome/ReaderProgressScrubFeedback.swift), including preparation at touch-down for the first tick.
- The chrome remains mounted and reverses one shared timeline so a rapid toggle can run it backwards without queued delayed reveals changing its state later. [Mode changes](../../Sources/YamiboXUI/Features/Reader/Shared/ReaderSessionView.swift) animate the presentation surface without carrying the animation into layout or restored scroll positions. The [loading overlay](../../Sources/YamiboXUI/Features/Reader/Shared/ReaderTransitionOverlay.swift) delays its appearance so cheap cached switches finish without flashing it. The stack [draws one diffuse shadow](../../Sources/YamiboXUI/Features/Reader/Shared/Chrome/ReaderToolbarStyle.swift) rather than letting individual capsule labels or glyphs cast shadows.
- In the [native curl adapter](../../Sources/YamiboXUI/Features/Reader/Shared/Paging/ReaderPagedPageTurnSupport.swift), the UIKit setter receives the visible front first for both edge spines, even if the data source orders sides differently. A turn away from the spine exposes the departing back; a turn toward it exposes the arriving back. Native turn and placement state filters selection echoes and layout replays. A second turn during a fade still takes effect immediately under the already-fading snapshot; taps on an outstanding turn must not restart it or trigger a boundary jump. [Slide animations](../../Sources/YamiboXUI/Features/Reader/Shared/Paging/ReaderPagedSlideAnimation.swift) move the real scroll position with a clock that a new touch cannot pause, keeping cell layout and shading in sync.
