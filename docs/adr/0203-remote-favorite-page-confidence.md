# 论坛收藏不把解析不确定当作空页

[收藏解析器](../../Sources/YamiboXCore/Library/Data/FavoriteHTMLParser.swift)必须区分确实为空和无法理解。部分收藏行无法解析不能作为可信的分页终点，避免把远端未加载的条目当作缺失；只把明确的空提示或没有列表项且文本为空的列表壳当作空。页码没有显式总数时不能从后退链接推断总页数小于当前页。[远端仓储](../../Sources/YamiboXCore/Library/Data/FavoriteRepository.swift)负责把不确定的页面变成错误，而非把它交给本地收藏操作当成完整数据。

版块收藏只在论坛上读取和管理，不镜像到本地收藏文档。版块页和帖子页共享删除操作，但只能提交从论坛解析出的数字收藏记录 ID；`favorite:<tid>` 是没有服务端 ID 时的 UI 标识，不能发给删除接口。未知记录 ID 的已映射帖子可通过帖子 ID 查询；提示用户是否删除远端和实际执行删除依赖同一个候选判断。批量新增按运行复用表单令牌，不为每条收藏重新加载用户资料。
