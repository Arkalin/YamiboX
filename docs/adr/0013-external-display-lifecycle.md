# 外屏阅读绑定会话所有者，而不是当前焦点

外屏专用场景不参与普通 SwiftUI 窗口导航，也不继承设备窗口的外观。所有者的设备控制器只登记一个 accessory：设备切到触控板、展示本机编辑面板或暂时打开原生帖子时，不重新登记；UIKit 因窗口焦点短暂变化断开 accessory 时，也不改选另一本书。候选与已打开的本机面板不随外屏设置禁用而丢弃，重新启用不要求重插显示器。

交接以视口可见和恢复状态为准。已在本机获准阅读的视口可以先完成位置恢复；尚未可见的外屏视口在前台重新开始挂载，避免丢失一次性布局或恢复回调。准备超时包含寻找挂载点的时间。保留面板的场景重连只恢复外屏内容，面板关闭前不恢复远程阅读输入；脱离的编辑器也不能把按键传给已隐藏的旧阅读器。遮罩和挂起时必须废弃在途手势。

隐私遮罩是 UIKit 承载控制器中位于 SwiftUI 内容之上的视图，而非模态面板。它保持阅读视口挂载，以便首次布局和恢复完成。退役时先覆盖黑色，再释放窗口、accessory 或所有者控制器，避免直接拆除时外部合成器保留阅读内容。当前等待只是尽力而为，不是外屏已呈现某一帧的确认；尚处于准备中的黑色窗口无需再次等待。
