# Preserve forum source while optimizing the native editor

Editor transactions use TextKit-compatible offsets in the same unchanged UTF-16 source without splitting surrogate pairs. Assemble the result in a single pass rather than repeatedly shifting the accumulated suffix. Apply only a verified same-leaf history composition as one replacement; structural edits must keep the individual reparses and node identities. The projection's optimized lookup preserves the reference traversal's tie order and falls back to the traversal if range boundaries are not monotonic. Affinity is part of the editing contract: for document leaf insertion at a boundary, the preceding leaf owns the insertion. Formatting balances differently styled selection edges without reserializing either unselected side. Aliases share toolbar behavior without changing source spelling, and changing only a block body does not rewrite its delimiters.

For BBCode tokenization, mask unterminated candidate bracket openings only in the matching input so a long malformed tail is not rescanned for each opening. Source range and spelling still come from the original string; the substitute character must not affect emoticon token ranges. For literal bodies, index the nearest close instead of searching each suffix. The HTML markup adapter uses a linear suffix scan for the first unquoted terminator of an opening tag: preserve quoted parameters, nonempty tag bodies and first-terminator behavior for comments. Parse only attribute-bearing branches with a DOM. Decode literal body entities once without collapsing author whitespace.

Import clipboard HTML through the Core DOM adapter, not a platform HTML renderer: importing must not execute markup or fetch remote images. When editing HTML paragraphs in TextKit, edited paragraph boundaries are serialized as line breaks. A projection whose block boundaries depend on surrounding text, or whose links are derived from the text being edited, must rebuild rather than splice stale spans. See [editor architecture](../architecture/forum-editor.md#选区块边界与增量更新).
