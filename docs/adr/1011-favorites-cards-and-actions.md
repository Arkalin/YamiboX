# Let the favorite card projection define its action scope

Use the [card projection](../../Sources/YamiboXCore/Library/Application/FavoriteLibraryProjectionTypes.swift) for opening a favorite and toggling its text cover, not the representative item's raw target or an independent read of settings. A Smart Comic Mode card opens with the board's manga scope and uses the directory cover if it has resolved. An individual card on the archive detail page instead opens its own thread and toggles its own cover. That keeps the chapter or cover an action affects in agreement with what the reader tapped, even when members share a directory.

- [Archive navigation](../../Sources/YamiboXUI/Features/Favorites/Cards/LocalFavoriteCardActions.swift) follows the same group key as projection: persisted directory ID when resolved, a provisional title-derived key otherwise. The displayed title is not a persisted identity. Viewing archive members is available without enabling archive-wide delete.
- [Selection](../../Sources/YamiboXUI/Features/Favorites/Engine/FavoriteLibraryOrganizer+Selection.swift) stores card IDs and resolves current group membership at execution instead of treating a representative chapter as the whole archive. Individual member cards inside archive detail act on the individual member. Archive-wide deletion is opt-in; the card menu and selection toolbar share the same confirmation flow. Hide actions that cannot apply to the selection rather than silently operating on only part of a mixed selection or offering a delete that does nothing.
- The [location picker](../../Sources/YamiboXUI/Features/Favorites/Shared/FavoriteMemberManagementSheet.swift) represents all, some, or no members in each location rather than a union that loses partial membership. Toggling partial membership adds the location to members missing it; toggling full membership removes it where doing so leaves at least one location.

## Presentation consequences

The decorative Smart Comic Mode badge can be hidden without changing action scope. List and grid cards attach it after selection emphasis so opacity compositing does not clip its outward offset. [Selection emphasis](../../Sources/YamiboXUI/Features/Favorites/Selection/LocalFavoriteSelectionActionBar.swift) reserves any content inset even when inactive, so selection does not reflow the layout. Rows, grid cards, and collection rows keep consistent selection padding; collection and item rows use the same cover dimensions. [Collection mosaics](../../Sources/YamiboXUI/Features/Favorites/Cards/LocalFavoriteCollectionCover.swift) retain tiles for members without images and tint only empty slots so the translucent text cover does not inherit the collection tint. [Text-only rows](../../Sources/YamiboXUI/Features/Favorites/Cards/LocalFavoriteItemRow.swift) use the text block as the transition source so opening still animates from the selected card.
