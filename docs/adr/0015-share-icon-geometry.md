# 桌面图标和 App 内渲染共享几何，不共享渲染产物

桌面图标保留 Icon Composer 的分层材质；App 内 SceneKit 按反向图层顺序挤出同一组路径，而不是从扁平预览反推曲线。分组时，镂空与所属花瓣必须留在一起，才能保持偶奇填充；[拆分脚本](../../scripts/split-app-icon.cjs)在两个分辨率比较无材质合成，拒绝改变原轮廓的输出。

[描摹脚本](../../scripts/trace-app-icon.cjs)沿原图前景与背景的色差估计覆盖率，再从抗锯齿边缘插值采样，避免把压成整像素的锯齿或色噪声误认作真实轮廓。多组分层图不能作为普通 `UIImage` 读取，[预览脚本](../../scripts/render-app-icon.sh)另存浅色和深色资源作为备用。操作步骤见[图标维护](../design/app-icon.md)。
