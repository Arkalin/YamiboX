# App 发布本地界面不等待远端同步

[App 入口](../../YamiboX/YamiboXApp.swift)拥有存储准备任务，目录验证、迁移和重试都在主 actor 之外运行，且窗口取消不终止共享工作。启动画面截止时间跨存储和窗口准备传递，不在每一阶段重新计时；品牌可见性在首帧前读出，以免已关闭品牌的用户看见短暂闪现。

[窗口模型](../../Sources/YamiboXUI/AppEntry/YamiboAppModel.swift)先呈现本地界面，再独立等待进程拥有的 WebDAV 启动同步。同步前采样当前窗口的位置，才能识别远端写入失败前本地已经合并的位置。共享结果与计算时的账号绑定；发布时必须重新校验账号和已经发生的导航，不能用迟到的继续阅读状态替换用户已打开的阅读器。组合入口解析启动参数，窗口仅接收语义化的导航目标。冷启动接到的接力活动优先于启动参数和本地继续阅读，处理前先认领，避免挂载重建后重放。

进程级的后台任务和通知委托在启动结束前注册，处理后台任务时可以异步等待存储就绪；否则冷启动通知不能可靠路由。主屏幕快捷操作由场景委托接收，冷启动通过场景连接选项，热启动通过回调，仍由 SwiftUI 创建窗口。前台收藏检查已有页面铃铛提示，通知仅更新角标，不重复显示横幅。

[启动更新提示](../../Sources/YamiboXUI/AppEntry/AppUpdateLaunchPrompter.swift)保留待展示状态，直到占位页或阅读器退场；自动检查仅提示新版本，不弹出“已是最新”或错误。跳过仅针对当前版本，手动检查仍报告完整结果。
