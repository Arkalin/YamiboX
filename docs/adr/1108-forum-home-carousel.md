# 宽屏轮播保留当前卡片和两侧预览

首屏未加载时以与内容相似的骨架保留布局。标题图比例较宽，常规宽度继续铺满会使 iPad 上的单张卡片过大，因此限制居中卡片宽度，用剩余空间显示相邻卡片。循环列表以三份数据提供两侧相邻项：只让中间副本参与无障碍读取；滚动停下后无动画跳到中间同内容位置。选中变化走最短的等价距离，自动从末项前进到首项时不会绕回去。页点以整条触控区域选择最近的一点；它们是重复的视觉提示，不作为 VoiceOver 的额外入口。板块的名称和标记在无障碍字号下改为上下排列，避免行内标记挤占标题。

自动轮播不会抢占手动浏览：用户选择后重新计时，程序自身的滚动动画不重置时钟；宽窄切换移除原容器时清除互动状态。减少动态效果时停用自动轮播，但仍可手动滑动。

入口：[论坛首页与轮播](../../Sources/YamiboXUI/Features/Forum/Home/ForumHomeView.swift)。
