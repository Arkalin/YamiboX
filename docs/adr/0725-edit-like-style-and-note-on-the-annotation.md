# 样式和笔记直接编辑已有喜欢条目

高亮颜色与下划线互斥，使用同一枚举和一行样式选项，而不是让颜色与下划线成为两个独立控制；图片没有染色的正文，不把高亮样式复用成图片标签。原本仅用黄色的旧记录迁移到默认黄色，保持外观。一条喜欢最多一条笔记，笔记不能脱离条目存在；用可空字段可让徽标、列表行和筛选共用一个是否有笔记的判断。空白文本清除笔记，不删除批注。

改样式或笔记不是建立新范围，不应通过可吞并相邻条目的高亮合并路径。真实的合并保留并按文档顺序拼接被合并的笔记，因为丢失用户写下的文字不可恢复；新的样式覆盖旧样式，合并后只有一条可着色的批注。写入返回被替代的 ID，使阅读器能清理对应的旧高亮。
