# 选择工具栏按系统版本挂载，但共用内容和理想宽度

[选择工具栏](../../Sources/YamiboXUI/SharedUI/Components/SelectionBottomToolbar.swift)在 iOS 26+ 交给原生 `.bottomBar` 绘制浮动胶囊，早期系统则在安全区底部自行提供胶囊外观；两条路径共用动作和等宽按钮布局。系统浮动栏以内容的理想宽度测量，普通 `HStack` 按每个按钮紧凑宽度求和，再平分时会截断最长标题。理想宽度因此按最宽单元乘以按钮数计算；外部给定有限宽度时仍填满它。

按钮用与原生标签栏相近的字号，并保留 Dynamic Type 与 44pt 触控高度。工具栏替换普通标签栏时，垂直留白用于维持相近高度。无法使用的动作从集合中移除；无可用动作时不展示一排禁用按钮。
