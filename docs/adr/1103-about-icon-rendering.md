# 关于页复用桌面图标的矢量轮廓，不读取图标栈

桌面图标的多组 `.icon` 栈交给系统渲染，不能当作普通 `UIImage` 加载；关于页需要可交互的立体图标，也不能使用设置页外观来切换实体背板。我们从同一矢量轮廓生成 [SceneKit 几何](../../Sources/YamiboXUI/Features/Settings/About/AboutIconGeometry.swift)，固定使用默认棕底，几何不可用时用导出的浅色普通图片兜底。资源的生成与验证见[图标维护](../design/app-icon.md)。

SVG 填充会隐式闭合轮廓，SceneKit 挤出前需显式闭合以封住接缝并保留镂空。正交相机让正面轮廓不随挤出深度而变化，并给拖动时倾斜的边角留余量。花瓣和花蕊从背板前表面挤出，不悬空，也不倒角侵蚀原始的小孔；柔光和反射与轮廓分开，限制反光避免米色花形与棕色背板失去区分度。

[交互场景](../../Sources/YamiboXUI/Features/Settings/About/AboutInteractiveIcon.swift)闲置时按需渲染，避免持续运行装饰动画。竖向拖动只有从图标上下边缘开始才驱动图标，中部保留给设置页面滚动；沿边旋转一圈后略微越过正面再回弹，不在一圈终点突然停下。
