# 可视编辑器块边界与选区回归

可视投影的隐式换行由前文是否为空、是否以换行结尾决定。普通文字编辑也可能改变后继块的换行；含这类结构的投影必须完整重建。`ForumComposerProjection.updating` 的结果应与对同一 document 完整重建相等，包括文本、spans、属性和来源映射。

以下场景记录回归契约。启动参数统一见 [launch-arguments.md](launch-arguments.md)。本次修复验证使用隔离宿主驱动，没有安装或启动 App。

## 插入后格式必须作用于选中字

1. 源文本为 `a\n[code]x[/code]uv`，其中 `\n` 表示真实换行。
2. 在代码块前换行之后输入 `y`，即原可视 UTF-16 offset 2。
3. 更新后投影为 `a\ny\n<代码块>\nuv`，代码块前仍有分隔换行。
4. 选择末字 `v` 并加粗。源文本必须为 `a\ny[code]x[/code]u[b]v[/b]`；不能修改 `u` 或静默无效。

## 删除后不能保留多余边界

1. 源文本为 `a\nb[code]x[/code]uv`。
2. 删除块前的 `b`，即原可视 UTF-16 range `{2, 1}`。
3. 更新后投影为 `a\n<代码块>\nuv`，不能保留两个相邻换行。
4. 选择末字 `v` 并加粗。源文本必须为 `a\n[code]x[/code]u[b]v[/b]`。

## 相关边界

- 对 quote、list、table、段落与其他会调用 boundary 的节点重复插入、删除和替换，保持增量入口与完整投影相等。
- 覆盖显式 LF/CRLF、空前文、已有换行、多个连续输入，以及组合字符、旗帜和 ZWJ emoji。使用合法 UTF-16 边界，不把代理项中间位置当成正常输入。
- 后继文本选区和格式化输出必须一致；撤销与重做应恢复相同源文本。输入触发完整重建后，可视选区按来源映射重新定位。
- 普通内联文本及 inline image/ruby 等不生成块边界的节点仍可增量更新；它们也必须满足完整投影契约。
- 用同一文档比较 projection 的完整值，避免以文本相等掩盖 spans/选区映射差异。另对格式后的源文本比较，避免把缓存与 UIKit 原地编辑文本相等误当成正确。

宿主验证只覆盖实际模型、命令、历史和投影方法。UIKit/IME/真实触摸选择属于独立交互边界，不能用宿主通过代替其结果。
