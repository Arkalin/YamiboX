# 核心流程回归清单

这是可重复执行的场景与预期，不是通过报告。只选择本次变更影响的项目；执行环境、构建、日志与证据要求见 [验证与故障诊断](README.md)，页面直达统一见 [测试 App 启动参数](launch-arguments.md)。默认使用本地论坛与 `YamiboX-Local`，不使用生产账号或远端数据。

## 数据准备

准备两个独立测试账号 A/B、可公开阅读与需要登录的帖子、多章节小说、含多图的漫画、跨帖智能漫画目录、普通帖子、标签以及附件。下载场景使用较大文件或本地限速，保证能观察暂停、重试和在途切换。同步使用专用本地 WebDAV 目录或服务，不连接用户既有远程备份。

记录账号 UID、帖子 ID 和必要设置，不记录口令或 Cookie。共享本地论坛时选择专用演示数据，重置前确认没有其他验证任务正在使用。

## 账号、启动与导航

| 操作 | 预期 |
| --- | --- |
| 用 A 登录，冷启动同一测试站 | 账号身份和既有数据按当前存储规则恢复；不会连接生产站 |
| A/B 切换，再打开个人资料、私信和论坛收藏 | 请求使用当前身份；账号私有内容不串号；共享本地设置不被误判为账号私有数据 |
| 加载、同步或下载期间切换账号/退出 | 旧任务结束或失效；迟到响应不能覆盖新账号页面、继续发送旧凭据或提交同步结果 |
| B 的会话失效后尝试切换，或在切换途中断网 | 显示认证/网络错误；不把未确认的身份发布成已登录，不错误覆盖当前身份 |
| 缺少、重复、冲突或无效启动参数 | 显示配置错误，不进入生产站；无效参数不触发站点数据清理 |
| 同站重启与切换到另一专用本地站 | 同站保留数据；站点身份变化按启动参数契约隔离并清理 Local App，不影响服务器与其他版本 |
| 页面直达、返回前台、导航栏和启动页设置 | 直达仅首个前台窗口执行一次；返回前台不重复跳转；非直达启动遵循用户启动页设置 |

站点切换/重置有删除本地数据的副作用，应最后执行，并记录前置数据。账号切换本身不能替代站点隔离验证。

## 论坛、标签与编辑器

| 操作 | 预期 |
| --- | --- |
| 论坛首页、板块分页、搜索、用户空间、普通帖子与网页回退 | 页面类型与链接目标一致；分页以服务端信息为准；权限错误不显示成空列表 |
| 快速翻页、刷新后离开、失败后重试 | 旧请求不回写；失败不清空上次成功内容；重试针对失败请求 |
| 标签首页、中文名称查找、ID 详情、分页、空态 | 原生标签页正确解析内容与服务器分页，重复行去重；边界详见[标签专项](forum-tags.md) |
| 发帖/回复/编辑，可视化与源码切换 | 内容、格式和附件一致；服务器权限和最终提交结果不由预览决定 |
| 在块前插删文字，再对块后文字加粗 | 无多余或缺失边界，选区映射正确；按[投影专项](forum-composer-projection.md)核对源文本 |
| 中文拼音组合输入、换行、粘贴、撤销重做、长按选区 | 不截断组合输入或 UTF-16 字符；撤销恢复源文本、选区与格式，不只恢复视觉文本 |
| 保存草稿、关闭重开；编辑途中切换账号 | 草稿恢复内容和提交目标；账号上下文不串号；上传中或迟到附件不能污染新会话 |
| 上传失败、提交失败、重试、取消 | 保留可恢复内容，明确错误；不静默丢稿；成功后以实际帖子确认，不凭按钮消失判定 |

## 阅读器、目录、位置与注解

| 操作 | 预期 |
| --- | --- |
| 小说短文、长文、含图片正文；分页与滚动往返 | 正文和图片完整；首尾可达；页码和百分比有效，结束位置可恢复 |
| 改字体、字号、间距、方向，旋转屏幕，再关闭重开 | 重排后恢复同一语义阅读位置，而非机械恢复旧页码；没有空白页或旧结构回写 |
| 小说目录跳转、搜索结果定位、书签和喜欢返回原文 | 对应正确章节/段落；定位状态与正文一致，不能只检查百分比 |
| 目录刷新、章节增删或跨页边界变化 | 进度与注解按身份/锚点恢复，不落到无关内容；失败保留可用内容并可重试 |
| 小说添加书签、选文摘录、修改笔记、删除再重开 | 操作保存并可检索；选文完整；重复操作和撤销不产生错误重复项 |
| 普通漫画缩放、横竖方向、单/双页和末尾奇数页 | 图片顺序一致，缩放/拖动可达，最后单页不丢失；位置恢复包含正确图片 |
| 智能漫画目录识别、手动编辑、跨帖跳章、刷新和重开 | 作品/章节身份稳定；目录和阅读位置一致，手动修改按既定规则保留 |
| 连续设置、快速跳章、加载中关闭阅读器、失败后重试 | 最新有效会话持有结果；旧请求不恢复关闭的页面或覆盖新章节/错误状态 |

必要时分别记录页码、百分比、章节标题与可见文本/图片锚点。页码一致不代表像素位置一致；内容重排后也不要求旧页码不变。性能改动按[诊断指南](README.md#日志与性能诊断)做相同条件的对照，不复用旧报告收益数字。

## 收藏、下载与离线

| 操作 | 预期 |
| --- | --- |
| 收藏/取消收藏、分类合集标签、封面调整、更新检查 | 当前账号论坛收藏与本地组织各遵循自己的边界；列表、数量和重启后结果一致 |
| 小说、漫画、附件加入队列，运行中追加或移除 | 队列顺序和总数更新正确；移除不计为完成，文件保存前不报告成功 |
| 暂停、继续、断网失败、重试及账号切换 | 状态明确；旧轮次回调不改变新队列；重试不重复累计旧传输字节 |
| 已完成项目重开，并在本地断网状态下阅读 | 已下载内容实际可用；未下载部分明确提示；技术缓存存在不等于下载完成 |
| 单项删除和批量清理下载 | 记录与文件均清理，存储统计更新；不顺带删除阅读进度、书签或论坛内容 |
| 前台发起队列后返回桌面，再返回 App | 记录实际系统授权与队列结果；模拟器不支持持续处理时不得记为后台活动通过 |

## WebDAV 与清理

| 操作 | 预期 |
| --- | --- |
| 未登录进入同步；无效地址、凭据和不可写目录 | 正确提示前置条件或错误，不生成虚假的成功时间 |
| 选择数据类别，上传、下载、重启后复查 | 仅处理启用类别；实际数据与结果一致；离线下载文件、封面图片不作为同步载荷 |
| 同一账号两端分别修改；删除后同步再下载 | 合并/删除按当前同步设计处理，不复活已删除项；记录冲突与重试结果 |
| 同步中改连接、改类别、切账号或取消 | 旧上下文不能写入新端点或账号，错误与状态不串用；失败可恢复 |
| 清理网页阅读缓存、图片缓存、其他缓存 | 对应技术缓存清除；用户离线下载与持久化封面不因普通图片缓存清理丢失 |
| 清理封面、进度、历史，以及取消确认 | 仅确认后删除对应数据；启用同步时展示删除传播提醒；取消不改数据 |
| 重置 App 后重新启动 | 本地账号、设置、数据库、文件及内存状态按重置规则刷新；生产 App 与服务器不受影响 |

有 WebDAV 的破坏性清理需使用专用数据，记录操作前后和再次同步后的结果。检查备份数据不包含凭据、离线文件或图像实体，并核对封面同步元数据与图片文件的区别。

## iPad、可访问性与真实硬件边界

- 对受影响页面覆盖 iPad 分栏、横竖屏、多窗口和窗口尺寸变化；重点检查返回路径、安全区域、阅读器双页、弹窗与键盘避让，不出现裁切、重叠或跨窗口状态污染。
- 影响共享 UI 时检查浅/深色、长标题、较大文字、VoiceOver 标签与可操作顺序；必要步骤不能只依赖颜色或图片说明。
- 模拟器可验证部分键盘导航与布局，但实体键盘、手柄、Apple Pencil、后台系统活动和真机性能需单独授权与设备记录。未执行的项目明确写“未验证”，不能以构建或模拟器通过代替。

每次记录使用“场景、前置、步骤、预期、实际、证据、状态”的平铺表格，状态区分通过、失败、环境受限和未执行；不要在本清单中累积某轮验收流水账。
